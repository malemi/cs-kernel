## Fixed design decisions

- One operator surface: `cs logs` (locations/recent/trace/health views; bounded JSON or prose). No shell hunt, no dependency on Claude transcripts or acceptance flags.
- Kernel root: `Settings.state_dir / "observability" / "owner-<sha256(selected UID)>"`; engine root: selected UID profile `/observability`. Stable component descriptor records actual package path/version/source digest, PID/start, installed workflow revision, log locations/access route, coverage and eviction gaps. No credential/config dump.
- Existing `cs_operator.log`, profile `zylch.log`, supervisor private native streams and notice queues remain referenced; structured events add joins and reliable decisions, not another business ledger.
- Event v1: event ID, UTC + monotonic duration/local sequence, component/process/start/version, trusted owner/profile, trace/run/attempt/span/parent, RPC/job/root/request-revision/draft/provider IDs when present, stage/start/result, reason enum, effect certainty, safe error code/class/relative frames, evidence reference. Missing IDs/coverage explicit.
- Reasons: auth/quota/permission/timeout/cancelled/incomplete-input/policy-hold/provider-rejection/persistence/logging/unknown. Observation states distinguish not-attempted, deferred, held, running, failed, accepted, verified, unknown-effect, delivered-cleanup-incomplete.
- Never assert SMTP acceptance means recipient delivery; never infer eligible-work absence from exit0/empty queues. Diagnostic context never grants permission, source trust or replay authority.
- Context propagation: process environment carries validated diagnostic run IDs only; async ContextVar plus explicit executor context copy for threads/jobs. Generate process identity locally. Join remote operations using a versioned top-level JSON-RPC `diagnostics` envelope, not handler params.
- Stopped-engine access: a separate per-profile reader (`engine/zylch/observability_reader.py`) reads the same private store without starting the engine. Authenticated bounded HTTPS GET locations/events/health, bearer credential from an env reference; fixed configured owner/root at service startup, no caller path/owner. TLS/reverse-proxy deployment explicit. `cs logs` uses this configured reader when engine RPC is unavailable; absent route reports missing coverage. Collector off-host delivery retains bounded event copies for host-outage investigation. Reader ownership: engine worker; HTTPS client/collector ownership: monitor worker.
- Capability `observability:1` advertises envelope + diagnostic reads. Legacy engine calls keep existing business behavior and local trace, reporting remote coverage unsupported; no silent claim of complete coverage. Do not add a capability round trip per instrumented stage.
- Engine derives profile/owner from its selected authenticated runtime; caller cannot set owner, storage path or authority. Validate IDs/size/types; ignore unsupported diagnostic metadata safely and report unlinked coverage, without altering business params/results/approval gates.
- Store append-only structured JSONL with bounded lock wait/event size and safe concurrent rotation; event IDs survive rotation, evicted intervals explicit. Existing private streams are references, not copied into ordinary events.
- Limits: structured 30d/512MiB per runtime, verbose 7d/128MiB, incidents 30d/64MiB; earlier age/size limit wins. Max event 8KiB, max diagnostic response 256KiB/page, max page 200 events, explicit continuation/gaps. No hidden clipping.
- Existing verbose retention: kernel owns `cs_operator.log` and its rotations (32MiB aggregate) plus supervisor native streams/manifests (96MiB aggregate); engine owns profile `zylch.log` and rotations (128MiB aggregate, replaces current ~600MiB). Each class expires at7d; fixed known producer roots only, no arbitrary directory sweep. M2 enforces age+aggregate bytes at write/startup and monitor scans, publishes eviction/drop ranges and incident-reference expiry. Preserve unrelated files; unresolved-incident evidence counts against a bounded documented reservation and reports loss when exhausted. Old unmanaged locations stay explicit coverage gaps until migrated.
- Strict metadata allowlist before persistence/export/model input. Private finance/legal/Qonto/Stripe/task paths retain existing metadata-only rules: safe fixed class/code/relative frames, never raw exception messages, locals, SQL, arbitrary tracebacks or documents. Other payloads/secrets/body text also excluded by default.
- Logger failures cannot change business return values or retry effects. Emit fixed safe stderr health signal + failed-write/drop counters; collector heartbeat expires when its store is unusable. Independent watchdog must catch total process/disk/host loss.
- Monitoring agent: separate deterministic service, not inside an operator tick. Every60s consume events + explicitly configured expected schedules/pause states + existing authoritative observations. It performs no classification/generation/mail action.
- Defaults: missed start +5min; missing progress +5min after declared stage deadline; incident delivery +5min after detection; monitor heartbeat60s, remote watchdog +5min. Interactive owed action deadline30min; scheduled owed action deadline next scheduled eligible tick +30min. Existing execution timeouts remain unchanged; deadlines trigger incidents, not cancellation/retry.

- Optional evidence-only analyst: metadata-only incident input; one call/incident revision, 60s, USD0.05/call, USD1/day, no tools capable of mutation/network beyond selected model.
